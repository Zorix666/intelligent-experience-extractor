## 检索指引

遇到排障 / 构建 / 部署 / CI/CD / 依赖 / 环境 / 配置 / 性能 / 稳定性任务时：
1. **先读本索引**：几十行文本，毫秒级扫描是否存在命中的问题现象；
2. **按关键词精准检索正文**：
   ```bash
   # 使用对应平台的文本搜索工具（如 Grep / SearchTool），仅读取命中的条目区块
   Grep pattern="<关键词>" path="<知识库路径>/experiences.md" -A 100
   ```
3. **引用并通知**：命中后在会话中提示用户「经验库中存在相关记录：〈标题〉」，并作为参考方案执行。
